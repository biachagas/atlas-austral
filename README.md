# Atlas Austral

Atlas Austral: catálogo de mapas, painéis interativos e bases de dados de Bianca Chagas. Cartografias de uma Internacionalista do Sul.

Endereço: https://biachagas.github.io/atlas-austral/

## Sobre o repositório

Site estático (HTML, CSS e JavaScript puros), sem etapa de build, sem CDN, sem cookies e sem rastreamento. Bilíngue (português e inglês).

O conteúdo dos produtos fica em arquivos de dados (`dados/`), um por produto, para que novos trabalhos possam ser acrescentados sem mexer no código.
